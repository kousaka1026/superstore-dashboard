# Dashboard layout

Current electronic layout, updated for month-level investigation. Author / team: Yule Liang.

```text
Sidebar                         Main page
----------------------          --------------------------------------------
Year                            Sales & profitability — Yule Liang
Market                          Intended user, decision, data period, refresh
Month (includes year)           Selected month's calendar-coverage status
Dataset source                  Current scope
                                Total Sales | Total Profit | Profit Margin
                                Historical monthly review message
                                Inspect review month (overview only)
                                --------------------------------------------
                                Monthly/daily trend Subcategory profit
                                - sales panel       - lowest profit first
                                - profit panel      - loss bars in red
                                --------------------------------------------
                                Metric definitions and expandable data notes
```

The headline numbers come first because they describe business scale and profitability.
The trends explain when performance changed; the profit ranking identifies where to
investigate. Year, market and month belong in the sidebar because they define the review scope.
The overview uses monthly totals; a selected month uses daily totals. Both charts
and all three metrics use the same records. The overview's review message states
the month being checked, and its button narrows the whole page to that month.
Detailed data limitations stay accessible at the bottom. No customer-level table or map
is included because neither is needed for the director's recurring profitability review.

The source exercise also requests a sketch on paper. This file provides the same layout
in the repository; it does not claim that a physical drawing has been made.
